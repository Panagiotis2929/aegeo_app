# Aegeo App

Το **Aegeo App** είναι ένας έξυπνος ταξιδιωτικός βοηθός (AI travel companion) που σχεδιάζει εξατομικευμένα δρομολόγια διακοπών στη Μεσόγειο, προσαρμοσμένα στις ανάγκες σου.

## Live Demo
Μπορείτε να δείτε την εφαρμογή ζωντανά εδώ:
👉 **[https://aegeo-app.vercel.app](https://y-rpkyranas-7601s-projects.vercel.app/)**

## Χαρακτηριστικά
* **Hyper-personalised itineraries:** Σχεδιασμός ταξιδιού με βάση την πόλη αναχώρησης, το budget και το "vibe" των διακοπών σας.
* **AI Integration:** Χρήση τεχνητής νοημοσύνης για μοναδικές προτάσεις.
* **Modern UI:** Καθαρό, μινιμαλιστικό design με αισθητική εμπνευσμένη από τη Μεσόγειο.
* **Quiz Mode:** Ένα διαδραστικό quiz για να ανακαλύψετε τον ιδανικό προορισμό για εσάς.
