# Aegeo App

An AI-powered travel companion that creates personalized vacation itineraries based on your preferences, budget, and travel style.

Designed to make trip planning effortless, Aegeo combines intelligent recommendations with a clean Mediterranean-inspired user experience to help travelers discover their perfect getaway.

---

## Overview

Aegeo App is an AI-driven travel planning platform that transforms a few simple user preferences into tailored travel experiences.

Whether you're looking for a relaxing island escape, an adventure-packed journey, or a luxury vacation, Aegeo generates destination suggestions and travel itineraries that match your unique travel profile.

## Project Status

Aegeo App is currently a **demo / MVP version** created to showcase the concept of an AI-powered travel planning platform.
