# Aegeo — AI Travel Companion 🧬🌊

**Aegeo** is an AI-powered travel companion application built with **React** and bundled using **Vite**. It features a modern, clean design system inspired by the Aegean, helping users discover their travel profile and view structured itineraries with an interactive AI chat assistant.

---

## 🚀 Features

*   **Design System:** Built with custom Aegean-inspired variables (sand background, ocean blues, and terracotta highlights) and a clean typography layout.
*   **Travel DNA Quiz:** A 3-question personality quiz that analyzes user preferences to discover their unique travel profile (*The Jetsetter*, *The Explorer*, or *The Slow-Traveler*).
*   **Smart Itinerary Planner:** Generates fully structured daily itineraries including activities, custom icons, times, and estimated costs based on budget configurations.
*   **Interactive AI Chat:** A live conversational interface to ask context-aware travel questions (e.g., about local food or weather conditions).

---

## 🛠️ Tech Stack & Architecture

*   **Framework:** React 18
*   **Build Tool:** Vite
*   **Styling:** Custom Modular CSS (`src/css/aegeo.css`)
*   **Routing & State:** Managed natively via React Hooks (`useState`) inside a dynamic single-page architecture (`src/main.jsx`).
